# MediCart Full-Stack E-Commerce Project

## Run on Node.js 24
1. Open Command Prompt in this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in your browser.

Admin page: `http://localhost:3000/admin.html`

The project uses Node.js + Express and Node.js 24's built-in `node:sqlite`, so no Python or better-sqlite3 build is required. The SQLite database `medicart.db` is created automatically.

This is a college/demo project. It does not implement real payment processing, authentication, prescription verification, or regulated pharmacy workflows.
